(infra/terraform/envs/primary/providers.tf), portanto todo recurso criado
pelo Terraform nasce etiquetado. Exemplo, no cluster EKS:

Ressalva documentada em docs/finops-forecast.md: alguns tipos de recurso
nao sao tagaveis pela AWS (associacao de route table, replication config
do ECR, OIDC provider) - limitacao da plataforma, nao de cobertura.

NOTA sobre a divergencia entre as duas fontes (ambas corretas):
  - Resource Groups Tagging API (CLI, acima): 60 recursos
  - Tag Editor do console (print 07b): 46 recursos
A diferenca nao e de cobertura de tags: o Tag Editor consulta apenas os tipos
que ele suporta ("All supported resource types" e a lista dele, nao a da conta),
enquanto a Tagging API devolve tudo que esta etiquetado. Os 14 a mais sao
majoritariamente sub-recursos de EC2/rede. Nenhum recurso etiquetado fica de
fora do total real.
